1""" 

2Structural type of the composed :class:`~flync.model.flync_model.FLYNCModel`. 

3 

4The domain mixins in this package are plain classes (not Pydantic models) that are always composed 

5into ``FLYNCModel`` at import time. Because Pydantic v2 would treat annotated attributes on a 

6non-model base class as fields, the mixins cannot declare ``self.ecus`` etc. directly; instead each 

7mixin method types its ``self`` parameter as this protocol so mypy can resolve the shared fields and 

8sibling methods without polluting the model schema. 

9"""
